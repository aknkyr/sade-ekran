# Sade Ekran

Ekran süresini azaltmak için minimalist Android ana ekranı.

- Büyük saat, günün tek hedefi, ikonsuz yazı listesi
- Instagram, TikTok, X uygulamalarını ve sitelerini (Chrome, Samsung Internet, Brave, Edge, Firefox, Opera) engeller
- YouTube'a sadece izin verilen saatlerde izin verir
- Seçilen uygulamaları açmadan önce bekleme ekranı gösterir
- Günlük deneme / açılış / vazgeçiş sayacı

## Kurulum

1. **Releases** bölümünden en son `SadeEkran.apk` dosyasını indir ve aç.
2. "Bilinmeyen kaynaklar" uyarısında Chrome'a izin ver, sonra **Yükle**.
3. **Ayarlar → Uygulamalar → Sade → ⋮ → Kısıtlı ayarlara izin ver** (Android 13 ve sonrası için gerekli).
4. Sade'yi aç → Ayarlar → **Engellemeyi aç** → Yüklü uygulamalar → **Sade Ekran engelleyici**'yi aç.
5. Ayarlar → **Varsayılan ana ekran yap** → Sade.
6. Ayarlar → **Ana ekrandaki uygulamalar** ile listeyi seç.

Her kod değişikliğinde GitHub Actions yeni APK'yı otomatik derler.
